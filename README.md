# Prodigy InfoTech Task 02 – Titanic Data Analysis

##  Overview

This project is part of the Prodigy InfoTech Data Science Internship – Task 02.

The objective is to perform data cleaning and exploratory data analysis on the Titanic dataset to understand factors associated with passenger survival.

##  Dataset

The project uses the Titanic dataset.

The dataset contains information about passengers, including:

- Passenger Class
- Survival
- Name
- Sex
- Age
- Siblings/Spouses
- Parents/Children
- Ticket
- Fare
- Cabin
- Embarked

##  Objectives

- Load and understand the Titanic dataset.
- Identify missing values.
- Perform data cleaning.
- Explore passenger characteristics.
- Analyze survival patterns.
- Create meaningful visualizations.

##  Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

##  Analysis

The project performs:

- Dataset exploration
- Missing-value analysis
- Statistical analysis
- Survival analysis
- Passenger demographic analysis
- Data visualization
